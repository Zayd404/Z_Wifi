
# Catatan Perubahan - Z_Wifi

Semua perubahan penting dalam proyek Z_Wifi akan dicatat di file ini.

## [1.0.0] - 2026-11-20

### Fitur Ditambahkan
- Pemindaian jaringan WiFi di sekitar perangkat.
- Analisis kekuatan sinyal WiFi berdasarkan RSSI.
- Analisis channel dan frekuensi WiFi.
- Informasi koneksi jaringan yang sedang digunakan.
- Penyimpanan dan penampilan riwayat pemindaian.
- Deteksi perangkat pada jaringan lokal.
- Animasi Loading pada proses tertentu.
- Sistem menu interaktif berbasis terminal.
- Konfigurasi aplikasi terpusat.
- Struktur kode Python modular.
- Tampilan terminal dengan warna.

### Platform
- Implementasi awal untuk Android melalui Termux.
- Dukungan Linux direncanakan.
- Dukungan macOS direncanakan.
- Dukungan Windows direncanakan.

### Dependensi
- Python 3.
- Colorama.
- Nmap untuk deteksi perangkat jaringan.
- Termux:API untuk implementasi Android.

### Catatan
- Pemindaian ditujukan untuk jaringan yang dimiliki atau telah mendapatkan izin.
- Ketersediaan fitur bergantung pada sistem operasi, perangkat keras, dan izin akses.
- Dukungan lintas platform masih dalam tahap pengembangan.
